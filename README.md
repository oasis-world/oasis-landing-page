# Oasis Village — Landing Page

Official marketing site for **Oasis Village (绿洲村)**.

Static site (no build step):

- `index.html` — entry
- `css/styles.css`
- `js/i18n.js`, `js/main.js`
- `assets/` — brand, scene maps, props, walk sprites

Open `index.html` in a browser, or serve the folder locally.

Bilingual zh/en (follows system language). Play Game URL is reserved (`href="#"`).
